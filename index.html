Trilha Python Full Stack Do zero ao avançado. Cada palavra no sentido literal.

Como usar esta trilha

Você começa sem saber programar. Cada aula acrescenta uma peça. Não pule a peça: a próxima usa o nome da anterior.

  1. Leia a aula. A frase depois de "Em palavras literais" diz exatamente o que a palavra significa.
  2. Copie o exemplo para o Laboratório e aperte Rodar. A saída é o que o programa fez.
  3. Mude um número ou um texto e rode de novo. Se a saída mudar, você entendeu.
  4. A aula de Prompts continua aqui. Ela ensina a pedir ajuda a uma IA. Não substitui a programação.

Ordem: peça 1 a 4 são o zero. Peças 5 a 8 são o básico. Peças 9 a 12 são o full stack. Peças 13 a 15 são o avançado.

1. O computador faz uma instrução de cada vez

Em palavras literais: uma instrução é uma ordem escrita. O programa é a lista de ordens. Ele começa na primeira linha e desce.

print("primeira")
print("segunda")

print significa "mostre este texto". As aspas marcam texto. Sem aspas, o nome é uma caixa, não o texto.

2. Variável: um nome para um valor

Em palavras literais: a caixa se chama nome. Dentro dela está o texto Ana. O sinal = guarda. Não compara.

nome = "Ana"
print(nome)

3. Tipo: o que pode ser feito com o valor

Texto se soma colando. Número se soma contando. Misturar os dois sem converter dá erro.

print("Ana" + " Souza")
print(2 + 3)
print("idade " + str(20))

str transforma o número 20 no texto "20".

4. Decisão: if

Em palavras literais: se a condição for verdadeira, rode o bloco recuado. Se não, rode o else. O recuo de 4 espaços é obrigatório.

nota = 7
if nota >= 6:
    print("aprovado")
else:
    print("recuperação")

5. Repetição: for

range(3) produz 0, 1 e 2. O bloco recuado roda uma vez para cada um.

for i in range(3):
    print(i)

6. Função: uma receita com nome

def guarda a receita. return devolve o resultado. Quem chama recebe esse resultado.

def dobro(n):
    return n * 2
print(dobro(4))

7. Lista e dicionário

Lista é uma fila numerada, começando em 0. Dicionário é uma caixa com etiqueta.

nomes = ["Ana", "Bia"]
print(nomes[0])
aluno = {"nome": "Ana", "nota": 8}
print(aluno["nota"])

8. Erro: leia a última linha

Quando o programa para, a última linha da mensagem diz o tipo do erro. NameError: você usou um nome que não existe. TypeError: você misturou tipos.

try:
    print(int("8"))
except ValueError:
    print("isto não é número")

9. Frontend: a tela

HTML é a estrutura. Um botão é uma etiqueta button. CSS é a aparência: cor, tamanho, espaço. JavaScript é o que acontece ao tocar. Frontend é essa tela. Em palavras literais: o que a pessoa vê.

10. Backend e API

Backend é o programa no servidor. A tela não abre o banco. Ela pede ao backend. Esse pedido se chama API. HTTP é a forma do pedido. GET pede para ler. POST pede para criar.

def criar_aluno(nome):
    return {"ok": True, "nome": nome}
print(criar_aluno("Ana"))

11. JSON

JSON é texto com chaves e listas. A API manda JSON para a tela conseguir ler sem adivinhar.

import json
texto = json.dumps({"nome": "Ana"})
print(texto)
print(json.loads(texto)["nome"])

12. CRUD e SQL

CRUD são quatro atos: criar, ler, atualizar, apagar. SQL é a língua do banco. INSERT cria. SELECT lê. UPDATE atualiza. DELETE apaga. A lista abaixo é o mesmo ato, sem banco.

alunos = []
alunos.append("Ana")
print(alunos)
alunos[0] = "Ana Souza"
alunos.pop(0)
print(alunos)

13. Avançado: classe

Uma classe é um molde. O objeto é a peça feita com o molde. self é a própria peça.

class Aluno:
    def __init__(self, nome):
        self.nome = nome
    def ficha(self):
        return "Aluno: " + self.nome
print(Aluno("Ana").ficha())

14. Avançado: módulo

Um módulo é outro arquivo com funções. import traz essas funções para este arquivo. No laboratório, os módulos da biblioteca padrão, como json e math, já existem.

import math
print(math.sqrt(9))

15. Avançado: o caminho de um produto

Em palavras literais, um produto full stack faz esta fila: a pessoa toca em Salvar; o JavaScript manda um POST; o Python confere o dado; o SQL grava; a API devolve JSON; a tela mostra "salvo". Teste é rodar um caso conhecido e conferir a saída. Deploy é colocar esse programa num servidor ligado, para outra pessoa abrir.

Você chegou ao avançado quando consegue escrever essa fila sozinho, com um exemplo pequeno, e explicar cada sigla da tabela sem olhar.

Prompt: como pedir a uma IA

Esta parte já existia. Continua aqui, com o sentido literal. Um prompt é o texto que você envia. A IA responde a esse texto. Ela não vê o que você não escreveu.

Use esta estrutura, preenchendo os colchetes:

Você é um [papel].
Sua tarefa é: [o que deve fazer].
Responda de forma [como deve responder].
Contexto: [o que a pessoa já sabe].

Exemplo literal:

Você é um professor paciente de programação.
Sua tarefa é: explicar o que é uma variável de forma simples.
Responda de forma curta e use uma analogia do dia a dia.
Contexto: a pessoa nunca programou.

O prompt pede explicação. Não executa o programa. Para ver o programa rodar, use o Laboratório.

Dúvidas literais

Programar é falar com a IA? Não. Programar é escrever a lista de ordens. A IA pode explicar. O Laboratório executa.

= guarda ou compara? Em Python, = guarda. Comparar igual é ==.

Por que o recuo importa? O Python usa o recuo para saber o que está dentro do if, do for e da função.

O que eu faço se der erro? Leia a última linha. Ela nomeia o erro. Volte à peça que ensinou aquele nome.
